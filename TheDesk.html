API keys

MLB Stats API and ESPN live scores are free and need no key. Everything below is optional — the simulator runs fully without any of them.

Backup

API keys are never included in this file — safe to upload to a GitHub repo or store anywhere. Re-paste your keys here after restoring. Do this before clearing Safari's site data, switching domains, or anything risky. Clearing your browser's site data for this domain deletes everything stored here — graded history, calibration, locked tickets, all of it — with no warning.

GitHub auto-sync

Pushes a credential-free file to data-backup.json in your repo. If this device ever starts up with zero graded history, it automatically pulls the last synced snapshot back down — no button, no prompt. Use a fine-grained token scoped to this one repo, "Contents: read and write" only.

Usage

Grading

Grading normally runs itself in the background the moment a game goes final — you shouldn't need this. Use it if something looks stale: force-fetches today's final scores, regrades every prop and side, recalculates calibration, grades every uploaded external pick, and settles any staked ticket that's now fully decided. Nothing here is destructive — it only fills in or corrects, never deletes.

Maintenance

Clears everything this page cached and reloads fresh. On iPhone Home Screen apps this usually works — if it still shows an old build number after this, force-quit the app (swipe it away in the app switcher) and reopen from the icon.
