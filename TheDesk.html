Usage

Backup

API keys are never included in this file — safe to upload to a GitHub repo or store anywhere. Re-paste your keys in Settings after restoring. Do this before clearing Safari's site data, switching domains, or anything risky. Clearing your browser's site data for this domain deletes everything stored here — graded history, calibration, locked tickets, all of it — with no warning. A hard reload (below) never touches this; clearing site data does. Export regularly, not just when something's about to change.

GitHub auto-sync

Pushes the same credential-free file to data-backup.json in your repo — same exclusions as manual export. If this device ever starts up with zero graded history (fresh install, wiped site data, new domain), it automatically pulls the last synced snapshot back down — no button, no prompt. Use a fine-grained token scoped to this one repo, "Contents: read and write" only — nothing else. That token is excluded from every backup it creates, same as your other keys.

The projection never touches bookmaker odds. It runs 10,000 simulations off confirmed lineups, per-plate-appearance rates, opposing starter, park factor, live weather, home/away splits, two-year head-to-head, and starter workload. Market prices are shown only to compare against — never to build it.

Most common outcome is the exact final score that came up more than any other across all 10,000 runs. That's a different and often more useful number than the median.
